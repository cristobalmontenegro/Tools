# 📖 FlippingBook

**ES:** Visor de **PDF con efecto de libro**: cada página es una hoja que se hojea con una animación realista de volteo. Hecho con HTML, CSS y JavaScript sobre [`turn.js`](https://github.com/blasten/turn.js) y [`pdf.js`](https://mozilla.github.io/pdf.js/). Funciona abriendo una sola página HTML, sin servidor.

**EN:** A **PDF viewer with a flipbook effect**: each page is a sheet you turn with a realistic flip animation. Built with HTML, CSS and JavaScript on top of [`turn.js`](https://github.com/blasten/turn.js) and [`pdf.js`](https://mozilla.github.io/pdf.js/). Runs by opening a single HTML page, no server needed.

---

## ✨ Características / Features

- Efecto de **hojear** páginas (turn.js) sobre un PDF real renderizado con **pdf.js**.
- Navegación con **flechas del teclado** y **clic en las esquinas** de la página.
- Diseño adaptable al tamaño de la ventana.
- **Sin back-end**: todo el procesamiento del PDF ocurre en el navegador.

---

## 🇪🇸 Cómo usarlo

1. Descarga el repositorio.
2. Coloca tu PDF en la carpeta y ajusta el nombre en `flippingbook.html` (por defecto usa `archivo.pdf`).
3. Abre `flippingbook.html` en tu navegador.
4. Pasa las páginas con las flechas ← → o haciendo clic cerca de los bordes.

### Archivos

| Archivo | Descripción |
|:---|:---|
| `flippingbook.html` | Página principal del visor. |
| `turn.js` | Librería del efecto de volteo de páginas. |
| `archivo.pdf` | PDF de ejemplo. |

---

## 🇬🇧 How to use

1. Download the repository.
2. Put your PDF in the folder and set its name in `flippingbook.html` (defaults to `archivo.pdf`).
3. Open `flippingbook.html` in your browser.
4. Turn pages with the ← → keys or by clicking near the page edges.

## 🛠 Tecnologías / Technologies

- `pdf.js` (renderiza el PDF a `<canvas>`)
- `turn.js` (efecto de libro)
- HTML5 + CSS3
