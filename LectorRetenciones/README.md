# 📄 LectorRetenciones

**ES:** Lector de **comprobantes de retención electrónicos del SRI (Ecuador)** que funciona **100% en el navegador**. No sube nada a ningún servidor: arrastras el archivo XML de la retención y la herramienta lo parsea y lo muestra en tablas legibles, listo para revisar o imprimir.

**EN:** A **fully client-side reader for Ecuador's SRI electronic withholding receipts**. Nothing is uploaded to a server: drop the withholding XML file and it parses and renders it into readable tables.

---

## ✨ Características / Features

- **100% local**: todo el procesamiento ocurre en el navegador (sin back-end, sin base de datos).
- **Arrastrar y soltar**: zona de *drop-zone* para cargar el XML, o selección por botón.
- **Vista legible**: presenta la información del comprobante (emisor, receptor, impuestos retenidos, totales).
- **Sin instalación**: es una única página HTML con CSS y JS embebidos.

---

## 🇪🇸 Español

### ¿Qué es un comprobante de retención?

Es el documento electrónico que emite un agente de retención en Ecuador para registrar los impuestos (Renta, IVA) que se descuentan a un proveedor. El SRI los entrega en formato **XML**. Este lector transforma ese XML técnico en una vista clara para el usuario.

### 🚀 Cómo usarlo

1. Descarga el repositorio.
2. Abre `lector_retenciones.html` en tu navegador (Chrome, Edge, Firefox…).
3. Arrastra el archivo `.xml` de la retención a la zona indicada, o haz clic para seleccionarlo.
4. Revisa los datos en pantalla.

### 📋 Requisitos

- Un navegador moderno. **No requiere** servidor, PHP, Node ni conexión a Internet.

---

## 🇬🇧 English

### What is a withholding receipt?

In Ecuador, a withholding receipt is the electronic document a withholding agent issues to record the taxes (income tax, VAT) deducted from a supplier. The SRI provides them as **XML**. This reader turns that raw XML into a clean, human-readable view.

### 🚀 How to use

1. Download the repository.
2. Open `lector_retenciones.html` in your browser (Chrome, Edge, Firefox…).
3. Drag the withholding `.xml` file onto the drop zone, or click to select it.
4. Review the data on screen.

### 📋 Requirements

- A modern browser. **No** server, PHP, Node or Internet connection required.
